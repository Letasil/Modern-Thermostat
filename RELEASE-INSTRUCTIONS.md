# GitHub release for Modern Thermostat

## Version 2.6.0

1. Open **Actions → Release → Run workflow**.
2. Enter `2.6.0` without a `v` prefix.
3. Review draft tag `v2.6.0` and title `modern-thermostat V2.6.0`.
4. Confirm the release contains the standalone asset `modern-thermostat.js` and manual-install ZIP `modern-thermostat-v2.6.0.zip`. Marketplace requires the JavaScript asset name to match exactly.
5. Publish only after the draft and installation are checked.

The ZIP contains `modern-thermostat.js` and `translations/` at the archive root. The JavaScript includes embedded translations as a fallback for single-file Marketplace installation.
